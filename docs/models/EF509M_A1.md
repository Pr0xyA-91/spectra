# Jura A1 Hardware & Memory Specification

## 1. Executive Summary & Model Identification
The **Jura A1** (Article Number: **15133** Piano Black, **15171** Piano White, Series: **A-Line**) is an ultra-compact, purist single-cup coffee machine designed exclusively for black coffee specialties. It features the Pulse Extraction Process (P.E.P.®) and an AromaG3 grinder, operating on the **EF509M** / **EF509P** control board platform.

* **Primary Firmware**: `EF509M` (e.g., `EF509M V01.26`)
* **Display Interface**: Symbol/Icon panel without a secondary display sub-bus (`TY$:` returns None)
* **Bootloader**: `R8C Loader V1.04` (Renesas R8C 16-bit CISC microcontroller architecture)
* **Power Rating**: `IC:AC03` (230V / 50Hz EU/CH)
* **EEPROM Architecture**: 256 words (512 bytes), 2-digit hex addressing (`0x00` - `0xFF`)
* **Factory Article Numbers**:
  - `15133`: Jura A1 Piano Black
  - `15171`: Jura A1 Piano White
  - `15125`: Jura A1 (EU / International)
  - `15110`: ENA Micro 101 Aroma+
  - `13594`: ENA Micro 1 Micro Black
  - `13636`: ENA Micro 1 Micro Silver

## 2. Beverage Dispensing Architecture (Single-Cup Model)
Unlike larger Jura machines, the A1 physical interface features only three touch buttons:
1. **Ristretto** (Symbol: $\Upsilon$)
2. **Espresso** (Symbol: $<$)
3. **Coffee** (Symbol: $>$)

Because the machine has no 2-cup dispenser or dual-brew capability, all preparations are strictly 1 cup (Total Preparations == Total Cups). The internal EEPROM counters are allocated as follows:

| EEPROM Word | Counter Name | Product Code | Typical Value (Customer Machine) | Cup Weight |
|---|---|---|---|---|
| `0x0006` | Total Ristretto | Code 1 | 477 | 1x Cup |
| `0x0004` | Total Espresso | Code 2 | 2,234 | 1x Cup |
| `0x0002` | Total Coffee | Code 3 | 1,954 | 1x Cup |
| **Sum** | **Total Cups** | — | **4,665** | **4,665 Cups** |

*Note: Words `0x0001`, `0x0003`, and `0x0005` remain `0x0000` on this single-spout platform.*
