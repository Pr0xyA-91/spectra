# Jura D4 (EF529M / Renesas RL78) Technical Specification & Memory Map

## 1. Overview & Appliance Architecture

The Jura D4 (Article Number: 15221, Series: D-Line) represents Jura's minimalist, bean-to-cup espresso and coffee machine featuring a symbol/icon interface without a full display screen or secondary display sub-bus MCU.

- **Electronic Control Unit (Mainboard)**: Renesas RL78 16-bit CISC Microcontroller
- **Mainboard Loader / Bootloader**: `BL_RL78 V01.30` (`TL:`)
- **Firmware Version**: `EF529M V01.02` (`TY:`)
- **Display Sub-Bus**: None (`TY$:` queries return null; front panel communicates via shift registers and key matrix directly to RL78 MCU)
- **Power Specification**: IC: `5700` (`IC:`)
- **Optical Interfacing**: 9600 Baud, 8N1, 4-digit hexadecimal address commands (`RT:XXXX`, `RE:XXXX`)
- **EEPROM / Data Flash Capacity**: 1024 words (2048 bytes), spanning `0x0000` to `0x03FF`. Addresses at `0x0400` mirror `0x0000` due to 10-bit address line wrap-around.

---

## 2. Telemetry & Hardware Sensors

### Live Diagnostic Telemetry (`HZ:`)
- **Thermoblock 1 (Coffee)**: Standard NTC probe (nominal ready-to-brew range: 90°C - 105°C)
- **Thermoblock 2 (Steam)**: Not Installed (Single Heater Architecture)
- **Brew Unit Encoder**: Optical quadrature encoder with nominal zero/mill position at 230 ticks (`0x0041`) and upper travel limit at 1296 ticks (`0x0047`).
- **Bean Hopper Sensor (`AS:`)**: Optical ambient vs. reflected infrared sensor. Nominal charged threshold: 99 ± 2 ADC delta counts.

## 3. EEPROM Memory Architecture & Register Mapping

### Block 0x0000: Maintenance & System Counters
| Address | Hex Code | Field Name | Description / Scaling |
|---|---|---|---|
| `0x0007` | `0x3B01` | `Coffee_System_Rinses` | Total coffee system rinsing operations (e.g. 15,105) |
| `0x0008` | `0x0055` | `Total_Cleaning` | Total hygiene cleaning cycles (e.g. 85) |
| `0x0009` | `0x001E` | `Total_Descaling` | Total descaling operations (e.g. 30) |
| `0x000A` | `0x7000` | `Grinder_Seconds` | Lifetime grinder run time in seconds (e.g. 28,672s = 7h 57m 52s) |
| `0x000E` | `0x0001` | `Total_Filter_Change` | CLARIS Smart filter replacement count (e.g. 1) |

### Block 0x0010: Operational Telemetry & Service History
| Address | Hex Code | Field Name | Description / Scaling |
|---|---|---|---|
| `0x0010` | `0x7192` | `Water_Volume_Total` | Cumulative water dispensed in deciliters (dl) (e.g. 29,074 dl = 2,907.4 L) |
| `0x0011` | `0x000E` | `Water_Hardness` | Configured water hardness in °dH (e.g. 14 °dH) |
| `0x0012` | `0x008F` | `Descaling_Agent_Volume` | Cumulative descaling agent consumed in deciliters (e.g. 143 dl = 14.3 L) |
| `0x0015` | `0x2E4B` | `Service_Counter` | Preparations since last service intervention (e.g. 11,851) |

### Block 0x0030: Production & Machine Identity
| Address | Hex Code | Field Name | Description / Decoding |
|---|---|---|---|
| `0x0030` | `0xCE24` | `Appliance_Number` | Factory Machine / Appliance Number (e.g. 52,772) |
| `0x0031` | `0x0002` | `Serial_Word` | Internal serial / batch production word (e.g. 2) |
| `0x0032` | `0x3AF0` | `Production_Date` | Bitfield: Day (bits 0..4 = 16), Month (bits 5..8 = 7), Year (1990 + bits 9..15 = 2019) -> 16.07.2019 |

## 4. Beverage & Dispensing Preparation Counters (Block 0x0330)

Unlike legacy Top-Tronic architectures which store drink counters at `0x0001`..`0x0006`, the Renesas RL78 platform allocates a dedicated beverage statistics bank at block `0x0330`:

| Address | Hex Code | Product Name | Double Serving | JOE Smart Connect Code |
|---|---|---|---|---|
| `0x0330` | `0x080D` | Espresso (Single) | No | Code 2 (`2,061`) |
| `0x0331` | `0x261B` | Coffee (Single) | No | Code 3 (`9,755`) |
| `0x0332` | `0x0002` | 2 x Espresso | Yes | Code 49 (`2`) |
| `0x0333` | `0x0003` | 2 x Coffee | Yes | Code 54 (`3`) |
| `0x0334` | `0x0007` | Hot water | No | Code 13 (`7`) |
| `0x0335` | `0x0000` | Ristretto (JOE only) | No | Code 1 (`0`) |
| `0x0336` | `0x0000` | Café Barista (JOE only) | No | Code 40 (`0`) |
| `0x0337` | `0x0000` | Barista Lungo (JOE only) | No | Code 41 (`0`) |
| `0x0338` | `0x0000` | Espresso Doppio (JOE only) | No | Code 48 (`0`) |
| `0x0339` | `0x0000` | 2 x Ristretto (JOE only) | Yes | Code 17 (`0`) |
| `0x033A` | `0x0000` | Ground Coffee Powder | No | Code 15 (`0`) |

### Total Calculation
$$\text{Total Preparations} = 2,061 + 9,755 + 2 + 3 + 7 = 11,828$$
$$\text{Total Cups} = 2,061 + 9,755 + (2 \times 2) + (3 \times 2) + 7 = 11,833$$
